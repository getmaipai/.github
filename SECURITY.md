# Security policy

MaiPai is private, local AI for families. Security and privacy issues are
taken seriously.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting ("Report a vulnerability"
under the Security tab of the affected repo). Please do not open a public
issue for a security problem.

You'll get a response as quickly as a solo maintainer can manage, usually
within a few days. Confirmed fixes ship as a release with a changelog note
crediting you (unless you prefer otherwise).

## Scope

All repos in the getmaipai org. Especially interesting: anything that could
expose a family's data off their own hardware, weaken the hub's local-only
promise, or leak personal information from the products or their docs.
